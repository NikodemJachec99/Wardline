## View it locally

The export ships its own runtime (`_runtime/`), so it works offline:

```bash
cd design/canvas
python3 -m http.server 8080
```

Then open http://localhost:8080/DashB.dc.html (or any other `*.dc.html`). Opening the files straight from disk or on github.com shows raw markup, because browsers block the scripts.

- `canvas.json`: the canvas index (artboards, positions, titles, notes).
- `*.dc.html`: one file per artboard (HTML + inline styles + a small script).
- `_runtime/`: React, ReactDOM and the canvas `support.js` needed to render the pages. Not part of the design.
- `EXPORT_README.md`: the README generated by the export, with every artboard title.

To implement, use `../handoff/` (tokens, Flutter ThemeExtension, component and screen specs). These files are the visual reference: exact colours, spacing and copy can be read from the inline styles.
