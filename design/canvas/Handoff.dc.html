iOS

  • NFC reads only through NFCNDEFReaderSession (via nfc_manager) started by a tap on "Start scanning". The system "Ready to Scan" sheet covers the app; set alertMessage to "Hold near the patient's wristband".
  • On read: stop the session, then run our brighten + haptic + quick summary sheet once the system sheet is gone. User cancel = silent return to the pre-scan screen.
  • Entitlement com.apple.developer.nfc.readersession.formats + NFCReaderUsageDescription in Info.plist. Camera: NSCameraUsageDescription.
  • Keep the Cupertino swipe-back. Pushed pages use the platform transition.
  • Safe areas: top inset ≈ 59pt, home indicator 34pt included in the 98pt tab bar.

Android

  • Scan screen enables reader mode while in the foreground and listens immediately: no "Start" button, no system sheet. Disable it in dispose.
  • Predictive back: android:enableOnBackInvokedCallback="true". Back closes the scanner and sheets; on a root tab it goes to Dashboard first, then leaves the app (PopScope).
  • NFC off: show "NFC isn't available" and switch to QR after 2s; offer system NFC settings.
  • Edge-to-edge (Android 15): draw behind the bars; nav bar 80dp + gesture inset.
  • Material ripples are allowed, but keep the Wl colours and the 0.98 press scale.

Both

  • One parser resolvePatient(code) for NFC and QR; regex ^HPT-[0-9A-HJKMNP-TV-Z]{8}$ before any query.
  • Camera denied → "Open Settings" (openAppSettings()), never a dead end.
  • Bundle Inter as an asset (offline-safe); tabular figures via FontFeature.tabularFigures().
  • Tablet layouts (Analytics, Ward monitor) at width ≥ 900dp; phone keeps the same card order, stacked.
  • Glass: no BackdropFilter. The header gradient behind it is flat, so blur is invisible and costs GPU. Use white 72% + a hairline.
